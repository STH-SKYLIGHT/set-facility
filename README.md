# SET 设施 · 概念展示页

在线访问：https://sth-skylight.github.io/set-facility/
源码仓库：https://github.com/STH-SKYLIGHT/set-facility

部署方式：GitHub Pages 从 main 分支根目录发布；后续更新网站文件并提交到该分支即可自动部署。

直接打开 `index.html` 即可浏览，也可作为纯静态文件托管；不需要安装依赖或启动后端。

## 内容与设计

- 首页：浅色观测界面、实时黑洞与弯曲公式。黑洞可拖动，聚焦后可用方向键移动。
- 共同理想：设定摘录与程序生成的环体线稿。
- 理解世界：虚实、能量与时间三个章节；桌面在限定区域内随原生滚动切换，也可点击或用左右键选择。窄屏及减少动效时保留普通标签切换。
- 向未知：环形空间图与精神宣言。
- 物质与心灵：现实与观测、万物的本源、人类思想、宇宙终局；原生阅读框支持 Esc、点击外部或关闭按钮退出。

文字选取设定笔记中的现实/能量/数维技术段落（5627–5636 行），人类的荒诞与庄重（484 行），宇宙终局片段（128–129 行），以及原有核心宣言。网页不展示相关设备名称或编号；部分段落按语义节选，明确标记为世界观设定或笔记摘录，而非科学论证。

视觉参考两段《明日方舟》特别映像的抽样关键帧：莱茵生命的浅色分层面板与细线编排、阿戈尔的环形建筑及空间层次；也阅读了 DSH 启动页、550C 与 rhine-lab-art 的开场和滚动代码。本站新增动效重新用轻量 CSS/SVG 实现，未引入其服务端、三维运行时或登录流程。

## 修改入口

- `index.html`：正文、图文切换配置及 `article-*` 阅读模板。
- `styles.css`：全站排版、开场、章节入场、图文和环体动效。
- `script.js`：导航、切换、阅读框、SVG 线稿及生命周期。
- `i18n.js`：中英文字典与语言切换；顶栏“中文 / EN”切换正文、阅读模板、图文配置和按钮提示，记住上次选择。中文原文仍保留在 HTML，新增或修改文案时同步维护字典；图片内部文字不自动翻译。
- `gravity.css` / `gravity.js`：黑洞布局、加载、暂停与后备显示。
- `assets/gravity-scene.js`：原始 Three.js 引力场景的本地适配；浅色映射使用已有输出 pass，不增加全屏 CSS 滤镜或第二个渲染场景。

## 性能与可访问性

黑洞约 30 fps，像素总量上限约 100 万，低档约 60 万；持续过慢或 WebGL 不可用时改为静态后备图。首页离屏、页面后台、阅读框打开及关闭动效时停止连续绘制。SVG/CSS 循环动画按章节可见性暂停，图片使用 WebP 和延迟加载。鼠标倾斜只作用于一个线稿面板，按动画帧合并输入。桌面技术展区采用 CSS sticky 与滚动触发更新，没有拦截滚轮，也没有新增连续渲染循环。

顶栏可暂停动效；尊重系统减少动态效果设置。保留原生滚动、键盘导航和阅读框焦点恢复，不劫持滚轮。开场约 2.45 秒，同一次会话只自动出现一次；可跳过、按 Esc 结束，或在新增展区末尾重播。键盘焦点转到正文时也会结束开场。减少动效或后台状态不播放。

本地浏览器检查不能代替真实移动设备 GPU 的性能测试。素材来源与归属见 `THIRD_PARTY.md`。

阅读框的入场动画独立于背景暂停：打开后只暂停 main 内动画，暂停动效模式直接显示阅读框，避免透明弹窗锁住页面。本站为冷白/蓝灰/深蓝主题；技术概念图由 SVG 绘制。

## 星域导览与新增动效

新增第 05 章位于“物质与心灵”之后，原有各章、阅读模板和 SVG 保持完整。`experience.css` / `experience.js` 单独承载新增样式、四景切换、视窗扫描、轻微滚动层次及开屏序列。

- 永恒视界：`aeternizon.webp`；新地球：`new-earth.webp` 与 `earth-city.webp`；超维天穹：以 `city-close.webp` 组成空间意象，不把城市图当作地形实录；丰碑：`monument.webp`。
- 轨道之间：`orbital.webp` 与 `shipyard.webp`。轨道结构图不被指认为永恒视界。
- 简写依据设定笔记的永恒视界/超维天穹段落及 SET 的 `descriptions.csv` 新地球、丰碑、轨道船坞条目。
- 星域切换支持按钮、前后箭头和键盘左右/Home/End。无 JS 时各景顺序展示。关闭动效会取消新增过渡并立即显示完整内容。
- 550C 的分幕面板、扫描刻度与视窗展开，以及阿戈尔关键帧中的层叠空间、环形构筑和冷色材质作为设计参考；没有加入其登录服务、音效或整套运行时。
- 不新增持续 JS 渲染循环。滚动变化按帧合并，仅在展区可见时更新 CSS 变量；切换动画有结束时间，后台或阅读框打开时暂停，离屏时清理过渡。

开屏加入斜切板片组装、环形刻度对位、分段进度轨和切幕揭示；各章首次进入视野时展开装饰板片，星域切换加入三片扫描闸门，技术图切换附带对位扫描。原有跳过、Esc、重播、暂停与减少动效设置继续有效。新增过渡均为有限动画，不增加持续 JavaScript 渲染循环；后台及阅读框打开时暂停，关闭动效时取消过渡并显示完整内容。
